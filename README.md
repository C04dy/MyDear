# MyDear

MyDear is a command line (or can be windowed(soon)), cross platform RPG engine that is built in rust  

## How To Run

-Editor: `cargo run --bin my_dear_editor --features editor`  
-Game:  
-Debug: `cargo run --bin my_dear` If you have a path to a project add this ` -- /Path/to/project/`  
-Release: `cargo build --release` and add the executable to the projects folder and run it there
